# 路由器全网速率（TrafficMonitor）

通过路由器 UPnP 的 WAN 字节计数器，把全网上下行总速率和今日流量显示在 TrafficMonitor 任务栏。

## 功能

- 四个任务栏项：
  - 「全网速率 ↑ / ↓」：实时速率
  - 「今日上传 / 今日下载」：当天 0 点以来的累计流量
- 项目文字可用 TrafficMonitor 的「显示文本设置」自定义；箭头和「今日上传」等只是默认文字
- 速率和流量都来自路由器 WAN 计数器：默认每秒采样一次，采样间隔可设为 200–5000 ms
- 自动通过 SSDP 发现路由器，不需要填写地址、账号或密码
- 关闭 TrafficMonitor 期间的流量会在下次启动时补进当天（见下方限制）
- 悬停显示：连接状态、更新时间、上下行速率、今日上传/下载

## 安装

1. 把 `RouterTotalSpeed.dll` 复制到 TrafficMonitor 的 `plugins` 目录
2. 重启 TrafficMonitor
3. 右键任务栏 → 选项 → 插件项目，勾选需要的项（四项默认都不勾选）

TrafficMonitor 1.86 的任务栏多行排列是「相邻项一组」：想让两个项目上下叠放，到「显示设置 → 设置项顺序」里把它们放到一起。

## 配置

右键任务栏 → 插件 → 路由器全网速率 → 选项：

- 显示单位：数值后是否带 `MB/s` / `Mbps`
- 单位：`MB/s` 或 `Mbps`（1 MB/s = 8 Mbps）
- 小数位：0 / 1 / 2 位，速率和流量共用
- 采样间隔：200–5000 ms，默认 1000 ms

设置和今日累计都在插件目录下的 `RouterTotalSpeed.ini`：`[Display]` 段是选项，`[Stats]` 段是今日累计和停机锚点。

## 显示含义

| 项目 | 含义 |
| --- | --- |
| `↑` / `↓` | 路由器 WAN 口的实时上行/下行总速率 |
| `今日上传` / `今日下载` | 当天 0 点以来经过 WAN 口的总字节数 |
| `查找中` | 启动后正在通过 SSDP 寻找路由器 |
| `无路由器` | 没找到支持 UPnP 的 IGD，请确认路由器已开启 UPnP |

只统计经过 WAN 口的流量，局域网内设备之间互传不会计入。

## 统计规则与限制

- 路由器计数器是 32 位，累计到 4 GiB 回绕；插件按相邻两次读数相减，运行中回绕和路由器重启都能正确处理
- 今日累计在 0 点清零
- TrafficMonitor 关闭期间：同一天内，重启后会把停机期间的增量补进当天；跨天无法归属，按当天从 0 起算
- 停机期间 WAN 流量超过 4 GiB 时，单点锚点分不清回绕圈数，补算可能少一截
- 只统计 TrafficMonitor 启动之后的用量，无法回填历史

## 适配其他路由器

只要路由器支持 UPnP 且实现 `WANCommonInterfaceConfig` 计数器即可，无需额外配置；发现是自动的。
UPnP 关闭的固件会在界面显示「无路由器」。

## 构建

需要 MinGW-w64（x64）：

```bat
build_mingw.bat
```

产物：`bin\Release\x64\RouterTotalSpeed.dll`（静态链接，无运行库依赖）。

## 目录

```
src/core   插件主类、显示设置、今日流量累计
src/router UPnP 发现与 WAN 计数器采样
src/net    WinHTTP、UTF-8 转换
src/ui     设置对话框、图标资源
tools      开发用冒烟测试（不参与构建）
```
